# PhishGuardX
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User specified Next.js, TypeScript, Tailwind, shadcn/ui, Framer Motion, Python FastAPI, scikit-learn and PostgreSQL. GitHub repository aashleshshet/PhishGuardX; Vercel deployment.
## Product Purpose
Explain possible phishing in email, links, QR codes and screenshots with visible evidence and limitations.
## Users
People assessing suspicious communications; portfolio reviewers evaluating practical defensive security engineering.
## Capabilities and Constraints
Never automatically visit submitted URLs. Do not forward private inputs to external AI. Real trained baseline models with documented evaluation. Local image processing. User-controlled history. Unknown evidence is not a clean verdict.
## Brand Commitments
Apple-inspired liquid glass, animations, Google Sans, dark and light themes. Product name PhishGuardX.
## Evidence on Hand
User project brief. No commercial usage or efficacy claims supplied. Dataset evaluation must be measured.
## Product Principles
Explain evidence, keep data handling explicit, make uncertain conclusions visible, use no invented risk percentages.
