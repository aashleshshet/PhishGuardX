# PhishGuardX design system
Mode: Operate. A quiet daylight workspace for making deliberate security decisions.

Google Sans is the sole type family, self-hosted. Cool blue-white background, deep navy text, cobalt actions, semantic amber/red/green only for findings. A fixed frosted sidebar and floating toolbar establish the liquid-glass material; broad translucent work surfaces, fine inner highlights, soft directional shadows, and an original dimensional shield form the visual identity. No ornamental charts or fabricated statistics.

Desktop: 232px sidebar, 36px content padding, asymmetrical welcome panel, four scanner shortcuts, activity and learning columns. Mobile: compact header with an accessible navigation drawer, single column tools, horizontally scrollable records only when needed. All actions have focus states; motion respects reduced-motion preferences. Theme changes preserve contrast. Status text never uses “safe” as a final verdict.

Animation: shield arrival and slow restrained float, active navigation spring, analysis progress transitions. Results prioritize verdict, observed evidence, unavailable checks, and actionable recommendations.
