# PhishGuardX design system
Mode: Operate. A readable workspace for making deliberate security decisions.

Google Sans is self-hosted under its bundled OFL license, with a system sans fallback. Body text is 16px; meaningful text never falls below 14px. Light mode uses white backgrounds, dark text and blue actions; dark mode uses black backgrounds, white text and red actions. Security verdicts retain red/amber/green semantics in both themes. A fixed frosted sidebar and floating toolbar establish the liquid-glass material; broad translucent work surfaces, fine inner highlights, soft directional shadows, and an original dimensional shield form the visual identity. No ornamental charts or fabricated statistics.

Desktop: 232px sidebar, 36px content padding, asymmetrical welcome panel, four scanner shortcuts, activity and learning columns. Mobile: compact header with an accessible navigation drawer, single column tools, horizontally scrollable records only when needed. All actions have focus states; motion respects reduced-motion preferences. Theme changes preserve contrast. Status text never uses “safe” as a final verdict.

Animation: shield arrival and slow restrained float, active navigation spring, analysis progress transitions. Results prioritize verdict, observed evidence, unavailable checks, and actionable recommendations.
